# 一、项目概述

## 1.1 游戏名称

Anchor（暂定）

## 1.2 游戏类型

Roguelike + Board Build（地图构筑）+ Grid Strategy（网格策略）+ High Score（高分构筑）

## 1.3 核心玩法

玩家通过移动扫描框，对亚空间中的局部区域进行扫描和锚定。

每次扫描都会获得分数（现实稳定度），同时改变地图，使地图不断成长。

玩家需要在有限回合内建立足够多的现实锚点，抵御亚空间怪物的侵蚀，最终锁定现实坐标，逃离亚空间。

# 二、游戏背景

## 2.1 世界观

公元 XXXX 年，人类开始探索深空。

探索舰 Anchor 在一次超空间跃迁过程中遭遇未知的亚空间乱流，整艘飞船被卷入亚空间。

这里不存在稳定的物理法则，空间不断变化，现实正在逐渐瓦解。

与此同时，大量亚空间生物开始侵蚀飞船。

飞船导航系统完全失效，无法定位现实宇宙。

舰长提出唯一可行方案：

利用飞船的 Reality Anchor（现实锚定装置），不断稳定局部空间，重新建立现实坐标。

只有建立足够多的现实锚点，才能重新连接现实宇宙，完成跃迁，逃离亚空间。

# 三、核心玩法

## 3.1 基础流程

每回合流程如下：

1. 亚空间生成元素
2. 玩家移动扫描框
3. 结算扫描区域内元素
4. 获得现实稳定度（分数）
5. 扫描区域永久留下地块效果
6. 亚空间重新生成元素
7. 进入下一回合

## 3.2 游戏目标

每个关卡存在一个现实稳定度目标。

例如：

- 第一章
  - 建立第一个现实锚点
  - 稳定度：300
- 第二章
  - 建立第二个现实锚点
  - 稳定度：900
- ……

完成目标后即可进入下一关。

# 四、地图系统

## 4.1 地图规格

地图大小：

6×6

每个格子属于一个独立空间节点。

每回合会随机刷新元素。

已经形成的地块不会刷新。

## 4.2 扫描器

玩家初始拥有：

2×2 扫描框。

扫描框可以自由移动。

每回合只能扫描一次。

后续可升级：

- 2×3
- 3×3
- 十字形
- L 型
- 整列扫描
- 双扫描器

扫描器升级属于永久 Build 内容。

# 五、元素系统

元素分为三大类。

## 5.1 资源元素

特点：

- 提供即时分数。
- 不会改变地图。

例如：

| 元素 | 稀有度 | 基础分数 | 地块增益 | 特殊效果 |
|---|---:|---:|---|---|
| 信号节点 | 普通 | 10 | 无 |  |
| 撕裂空间 | 非凡 | 30 | 随机摧毁一个地块加成 |  |
| 超频 | 非凡 | 30 | 此地块分数之后结算 / 2 |  |
| 数据 | 普通 | 12 | 无 | 框中每存在一个数据，分数…… |
| 棱镜 | 非凡 | 6 | 无 | 将左边的分数叠加到自身…… |
| 引力流 | 普通 | 14 | 无 | 遇到信号节点时将每个信号的增加分数添加到自身…… |
| 能量碎片 | 非凡 | 10 |  | 给予框内所有元素 +5 分 |
| 多维分析 | 非凡 | 6 | 无 | 框中每有一个不同的元素，+3 |
| 能量跃迁 | 核心 | 5 |  | 获得框中所有地块的加…… |
| 共振信号 | 非凡 | 8 |  | 如果框中有 >=50% 的频率某一元素，获得 20 分 |
| 混乱信号 | 普通 | -10 到 30 | 无 |  |
| 虚无信号 | 普通 | 20 | 无 | 随机消耗掉相邻的一个…… |
| 阻塞信号 | 非凡 | 30 |  | 这个给地块不能再给予…… |

部分资源之间存在联动。

例如：

晶体 + 能量：额外 +5。

稀有度划分：

| 名称 | 权重 |
|---|---:|
| 普通 | 100 |
| 非凡 | 50 |
| 核心 | 25 |

## 5.2 锚定元素

特点：

- 基础分数较低。
- 会永久改变当前格子。

例如：

| 元素 | 稀有度 | 基础分数 | 地块效果 |
|---|---:|---:|---|
| 现实锚点 | 普通 | 0 | 放置在这个地块上的元素分 +5 |
| 信号加强点 | 非凡 | 2 | 如果是信号节点放置在这一地块之上的时候分数 *2 |
| 双重激发 | 核心 | 1 | 在这个地块上面的元素激发 2 次 |
| 成长节点 | 非凡 | 2 | 在这个每次结算地块分数 +2（永久成长 +2，+4，+6，+8……） |
| 现实链接 | 非凡 | 1 | 在这个地块上面会生产 0.5-3 倍的效果的信号节点 |
| 空间乱流 | 核心 | 0 | 地块上元素每回合 -1 永久分，但是结算分数 *2 |
| 能量元素 | 核心 | 2 | 在这个地块上每个回合达到 5 分，多获得一个回合次数 |
| 信号献祭 | 非凡 | 1 | 上下左右分数 *2，中心元素 / 8 |
| 数据流 | 非凡 | 2 | 有 20% 的概率将框中非数据的元素转换为数据 |
| 宇宙棱镜 | 核心 | 2 | 将左边地块的元素分数复制到自己的分数上 |
| 稳定场 | 非凡 | 2 | 这个格子免疫污染和衰减效果 |
| 炎热核心 | 非凡 | 3 | 初始 +0，将框中最低基础分数的元素摧毁加成到这个格子当中 |
| 磁场 | 普通 | 2 | 随机吸引相邻格子元素进入此格子当中 |
| 混乱场 | 非凡 | 2 | 每 3 回合生成 3 个混乱信号 |
| 信号转换 | 普通 | 3 | 随机将框中的一个元素转换为信号 |
| 信号加强器 | 普通 | 3 | 每有一个名字带有“信号”的元素分数 +5 |
| 混乱立场 | 核心 | 0 | 混沌信号在框中结算，结算分数 *3 |

## 5.3 加成道具

可以选择在三选一界面出现。

| 名字 | 稀有度 | 效果 |
|---|---:|---|
| 信号稳定技术 | 核心 | 将混乱信号和虚无信号转换为普通的信号节点 |
| 过载 | 非凡 | 当结算是分数 >30，分数 +10% |
| 极限扫描 | 非凡 | 当框中元素只有 1 种时，分数 *2；元素有 2 种时，分数 +10；当元素有 3 种时，无效果；当分数大于三种时，分数 -20 |
| 空间保留 | 普通 | 随机保留框外的 4 个元素 |
| 时间回溯 | 核心 | 保持一回合全部元素不变 |
| 能源探查 | 核心 | 增加能源碎片和能源元素的出现概率 |
| 清洁机器人 | 非凡 | 30% 的概率清除一个在地块上的 defull |
| 混沌转化 | 核心 | 地块上每有一个 defull，分数结算时，+5 |
| 即使止损 | 非凡 | 地块上面的 defull 效果减半 |
| 孤注一掷 | 非凡 | 剩余越少的回合数，然后加成倍率越高（当回合数只剩下 1 回合时，最后一次结算 +2） |
| 双重扫描 | 核心 | 扫描两次 |

# 八、怪物系统

亚空间怪物不会直接攻击玩家。

而是影响地图。

例如：

| 名字 | 效果 |
|---|---|
| 秦伦虫族 | 随机吞噬 x 个格子上的加成（x 至少为 1，至多为 3） |
| 混池 | 第一次洗牌时后你可以看到所有的元素，之后的回合中你的元素都是不可见状态 |
| 恐虐 | 要求达到的分数特别高 |
| 消除 | 暂时屏蔽某一个地块上的加成 |
| 杀手 | 元素基础加成分 / 2 |
| 暴食 | 个数值或者说就是要达到的分数…… |

怪物属于局内压力来源。

# 九、成长系统

每完成一个现实锚点。

玩家可获得一次强化。

强化采用 Roguelike 三选一。

例如：

- 扫描器扩大。
- 锚定元素效果 +50%。
- 所有资源元素 +20%。
- 首次扫描双倍。
- 污染减少 50%。
- 获得额外扫描次数。

玩家可围绕不同方向构筑流派。

# 十、胜负条件

## 胜利

建立全部现实锚点。

成功锁定现实坐标。

飞船脱离亚空间。

## 失败

现实稳定度归零。

飞船被亚空间吞没。

或飞船耐久归零。

# 十一、设计理念

本作的核心体验并非传统 Roguelike 的“卡组构筑”，而是“地图构筑（Board Building）”。

玩家通过不断扫描亚空间、锚定现实节点，将原本混乱且不断变化的空间逐渐改造成一张具有高效联动和高收益的现实网络。在此过程中，玩家既要规划长期的地图成长路线，又要应对亚空间污染和怪物侵蚀带来的即时压力，在有限回合内完成现实坐标的锚定，最终逃离亚空间。
