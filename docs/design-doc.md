# 《Anchor（暂定）》游戏策划案

## 一、项目概述

### 1\.1 游戏名称

**Anchor（暂定）**

### 1\.2 游戏类型

Roguelike \+ Board Build（地图构筑）\+ Grid Strategy（网格策略）\+ High Score（高分构筑）

### 1\.3 核心玩法

玩家通过移动扫描框，对亚空间中的局部区域进行扫描和锚定。

每次扫描都会获得分数（现实稳定度），同时改变地图，使地图不断成长。

玩家需要在有限回合内建立足够多的现实锚点，抵御亚空间怪物的侵蚀，最终锁定现实坐标，逃离亚空间。

# 二、游戏背景

## 2\.1 世界观

公元XXXX年，人类开始探索深空。

探索舰 **Anchor** 在一次超空间跃迁过程中遭遇未知的亚空间乱流，整艘飞船被卷入亚空间。

这里不存在稳定的物理法则，空间不断变化，现实正在逐渐瓦解。

与此同时，大量亚空间生物开始侵蚀飞船。

飞船导航系统完全失效，无法定位现实宇宙。

舰长提出唯一可行方案：

> 利用飞船的 Reality Anchor（现实锚定装置），不断稳定局部空间，重新建立现实坐标。
> 
> 

只有建立足够多的现实锚点，才能重新连接现实宇宙，完成跃迁，逃离亚空间。

# 四、地图系统

## 4\.1 地图规格

地图大小：

6×6

每个格子属于一个独立空间节点。

每回合会随机刷新元素。

已经形成的地块不会刷新。

---

## 4\.2 扫描器

玩家初始拥有：

2×2扫描框。

扫描框可以自由移动。

每回合只能扫描一次。

后续可升级：

- 2×3 

- 3×3 

- 十字形 

- L型 

- 整列扫描 

- 双扫描器 

扫描器升级属于永久Build内容。

# 九、成长系统

每完成一个现实锚点。

玩家可获得一次强化。

强化采用 Roguelike 三选一。

例如：

扫描器扩大。

锚定元素效果\+50%。

所有资源元素\+20%。

首次扫描双倍。

污染减少50%。

获得额外扫描次数。

玩家可围绕不同方向构筑流派。

## 失败

---

# 十一、设计理念

本作的核心体验并非传统 Roguelike 的"卡组构筑"，而是"地图构筑（Board Building）"。

玩家通过不断扫描亚空间、锚定现实节点，将原本混乱且不断变化的空间逐渐改造成一张具有高效联动和高收益的现实网络。在此过程中，玩家既要规划长期的地图成长路线，又要应对亚空间污染和怪物侵蚀带来的即时压力，在有限回合内完成现实坐标的锚定，最终逃离亚空间。
